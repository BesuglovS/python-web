## Что такое f-строки?

f-строки (formatted string literals) — это самый удобный способ вставки значений переменных в строку. Появились в Python 3.6 и стали стандартом для форматирования.

```python
name = "Максим"
age = 25
print(f"Привет, {name}! Тебе {age} лет.")
# Привет, Максим! Тебе 25 лет.
```

Синтаксис: перед строкой ставится буква `f`, а переменные или выражения пишутся внутри фигурных скобок `{ }`.

Чтобы вывести фигурные скобки буквально, их удваивают:

```python
print(f"{{фигурные скобки}}")   # {фигурные скобки}
```

f-строки можно заключать и в одинарные, и в двойные кавычки: `f'Привет, {name}!'` и `f"Привет, {name}!"` работают одинаково. Внутри выражения допустим другой тип кавычек — например, `f"|{'текст':<10}|"`.

> **💡 Совет:** начиная с Python 3.12 (PEP 701) внутри f-строки можно использовать те же кавычки, что и снаружи (`f"{d["key"]}"`), а также многострочные выражения. В более старых версиях используйте другой тип кавычек.

## Сравнение способов форматирования

```python
name = "Анна"
age = 30

# Старый способ (оператор %)
print("Привет, %s! Тебе %d лет." % (name, age))

# Метод .format()
print("Привет, {}! Тебе {} лет.".format(name, age))

# f-строка — самый современный и читаемый
print(f"Привет, {name}! Тебе {age} лет.")
```

> **💡 Совет:** для нового кода используйте f-строки: они читаются лучше и, как правило, работают быстрее `%` и `.format()`.

## Выражения внутри f-строк

```python
a = 10
b = 3
print(f"{a} + {b} = {a + b}")     # 10 + 3 = 13
print(f"{a} / {b} = {a / b:.2f}") # 10 / 3 = 3.33

# Вызов функций внутри f-строк
name = "python"
print(f"{name.upper()} — это круто!")  # PYTHON — это круто!

# Тернарный оператор
score = 85
print(f"Результат: {'Сдал' if score >= 60 else 'Не сдал'}")
```

Если нужно не «человеческое», а отладочное представление значения, используйте `!r` — это аналог `repr()`:

```python
v = "Python"
print(f"{v}")    # Python
print(f"{v!r}")  # 'Python' — видно кавычки
```

## Форматирование чисел

<table class="lesson-table"><thead><tr><th scope="col">Спецификация</th><th scope="col">Пример</th><th scope="col">Результат</th></tr></thead><tbody><tr><td><code>:.2f</code></td><td><code>f"{3.14159:.2f}"</code></td><td>3.14</td></tr><tr><td><code>:.0f</code></td><td><code>f"{3.99:.0f}"</code></td><td>4</td></tr><tr><td><code>:.1%</code></td><td><code>f"{0.85:.1%}"</code></td><td>85.0%</td></tr><tr><td><code>:,</code></td><td><code>f"{1000000:,}"</code></td><td>1,000,000</td></tr><tr><td><code>:+</code></td><td><code>f"{42:+}"</code></td><td>+42</td></tr></tbody></table>

```python
pi = 3.1415926535
print(f"Число π ≈ {pi:.4f}")    # Число π ≈ 3.1416
print(f"Число π ≈ {pi:.2f}")    # Число π ≈ 3.14
print(f"Число π ≈ {pi:.0f}")    # Число π ≈ 3
print(f"Население: {1000000:,}")  # Население: 1,000,000
print(f"Успеваемость: {0.85:.1%}")  # Успеваемость: 85.0%
print(f"Цена: {1234.5:,.2f}")    # Цена: 1,234.50
print(f"Температура: {5:+d}")    # Температура: +5

# Перевод чисел в другие системы счисления
n = 255
print(f"{n} в двоичной:          {n:b}")  # 255 в двоичной: 11111111
print(f"{n} в восьмеричной:      {n:o}")  # 255 в восьмеричной: 377
print(f"{n} в шестнадцатеричной: {n:x}")  # 255 в шестнадцатеричной: ff
print(f"{n} в HEX (верхний регистр): {n:X}")  # 255 в HEX (верхний регистр): FF
```

> **⚠️ Важно:** округление при выводе (`:.0f`, `:.2f`, `round()`) использует **банковское правило**: при ровно половине выбирается чётная цифра. Поэтому `f"{2.5:.0f}"` даёт `"2"`, а `f"{3.5:.0f}"` — `"4"`. Кроме того, двоичное представление `float` даёт сюрпризы: `f"{2.675:.2f}"` равно `"2.67"`, а не `"2.68"`. Для денежных расчётов используйте `decimal`.

## Выравнивание текста

```python
# Выравнивание по правому краю (ширина 10)
print(f"|{25:>10}|")   # |        25|

# По левому краю
print(f"|{'текст':<10}|")  # |текст     |

# По центру
print(f"|{'Python':^10}|") # |  Python  |

# Заполнение символом
print(f"|{25:0>5}|")       # |00025|
print(f"|{'abc':-^7}|")    # |--abc--|
```

Ширину можно передать переменной — это удобно при построении таблиц:

```python
width = 8
print(f"|{'итог':>{width}}|")   # |   итог|
```

## Практические примеры

> **ℹ️ Замечание:** в примерах ниже используются циклы (`for`), словари и `enumerate` — это темы следующих уроков. Сейчас достаточно запустить код и посмотреть на результат.

```python
# Таблица умножения
for i in range(1, 5):
    for j in range(1, 5):
        print(f"{i} × {j} = {i*j:>2}", end="  ")
    print()

# Отображение цен
products = {"apple": 79.90, "milk": 120.00, "bread": 55.50}
for name, price in products.items():
    print(f"{name:.<20} {price:>8.2f} ₽")

# Вывод списка с нумерацией
fruits = ["яблоко", "банан", "вишня"]
for i, fruit in enumerate(fruits, 1):
    print(f"{i}. {fruit}")
```

## Debug-режим: {x=}

```python
x = 42
y = 3.14
print(f"{x=}")          # x=42
print(f"{x=} {y=}")    # x=42 y=3.14
print(f"{x+y=}")       # x+y=45.14

# Вместе с форматом
print(f"{y=:.1f}")     # y=3.1

# Очень удобно для отладки:
name = "Максим"
print(f"{name=}")      # name='Максим'
```

## Итоги

- f-строка включается буквой `f` перед кавычкой, выражения — в фигурных скобках.
- `{{` и `}}` выводят фигурные скобки буквально.
- Формат задаётся после двоеточия: `{значение:спецификация}`.
- `:.2f` — знаки после запятой, `:,` — разделители тысяч, `:+` — знак, `:<^>` — выравнивание.
- `{x=}` выводит имя переменной и значение — удобно для отладки.
