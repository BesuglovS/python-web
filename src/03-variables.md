## Что такое переменная?

Переменная — это имя для области памяти, в которой хранятся данные. В Python переменная создаётся в момент первого присваивания:

```python
name = "Анна"
age = 25
pi = 3.14159
```

Тип переменной определяется автоматически (динамическая типизация):

```python
x = 10        # int
x = "hello"   # теперь str
x = 3.14      # теперь float
```

## Правила именования

- Имя может содержать буквы, цифры и символ подчёркивания `_`
- Не может начинаться с цифры
- Не может содержать дефис: `my-var` Python прочитает как `my - var` (вычитание)
- Регистр имеет значение: `age` ≠ `Age`
- Нельзя использовать ключевые слова Python (`if`, `for`, `while`, `class`, `def`, `return` и др.)
- В Python 3 разрешены буквы Unicode, в том числе русские: `возраст = 25` — допустимое имя (но PEP 8 рекомендует латиницу)

> **💡 Совет:** **PEP 8 — стиль:** используйте `snake_case` для переменных: `user_name`, `total_count`.

## Множественное присваивание

```python
a, b, c = 1, 2, 3
a = b = c = 0     # всем трём присвоится 0
```

## Копирование значения

Присваивание `y = x` копирует значение, а не создаёт «связь» между именами. Числа неизменяемы, поэтому последующее изменение `x` не затрагивает `y`:

```python
x = 10
y = x      # y получает значение 10
x = 5      # x теперь 5, но y по-прежнему 10
print(y)   # 10
```

## Вывод нескольких значений

`print()` умеет выводить несколько значений сразу — по умолчанию они разделяются пробелом:

```python
a, b = 1, 2
print(a, b)   # 1 2
```
