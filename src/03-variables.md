## Что такое переменная?

Переменная в Python — это **имя, которое ссылается на объект**. Само значение хранится в объекте, а имя лишь указывает на него. Переменная появляется в момент первого присваивания:

```python
name = "Анна"
age = 25
pi = 3.14159
```

Тип определяется автоматически (динамическая типизация). Важно понимать: тип принадлежит **значению**, а не имени, поэтому одно и то же имя может в разное время указывать на объекты разных типов:

```python
x = 10        # int
x = "hello"   # теперь str
x = 3.14      # теперь float
```

## Правила именования

- Имя может содержать буквы, цифры и символ подчёркивания `_`
- Не может начинаться с цифры: `2nd_place` — ошибка
- Не может содержать дефис: `my-var` Python попытается прочитать как вычитание `my - var` (а в левой части присваивания это `SyntaxError`)
- Регистр имеет значение: `age` и `Age` — разные переменные
- Нельзя использовать ключевые слова Python (`if`, `for`, `while`, `class`, `def`, `return`, `import`, `None`, `True`, `False` и др.); полный список выводит `print(keyword.kwlist)` после `import keyword`
- В Python 3 разрешены буквы Unicode, в том числе русские: `возраст = 25` — допустимое имя (но PEP 8 рекомендует латиницу)

> **💡 Совет:** Не называйте переменные именами встроенных функций (`list`, `print`, `sum`, `max`, `id`, `type`). Иначе имя «затенит» функцию, и вызвать её уже не получится:

```python
list = [1, 2]        # так делать не стоит
# list("abc")        # TypeError: 'list' object is not callable
```

## Соглашения об именах (PEP 8)

- **`snake_case`** для переменных и функций: `user_name`, `total_count`
- **`UPPER_CASE`** для констант: `MAX_SIZE = 100`
- **`_`** для ненужного значения: `for _ in range(10)`
- Осмысленные имена: `price`, а не `p`

## Множественное присваивание

```python
a, b, c = 1, 2, 3
a = b = c = 0     # всем трём присвоится 0
```

Отдельный приятный бонус Python — обмен значений без промежуточной переменной:

```python
a, b = 1, 2
a, b = b, a       # a = 2, b = 1
print(a, b)       # 2 1
```

> **⚠️ Важно:** `a = b = c = []` создаёт **один** список, на который ссылаются все три имени. Для независимых коллекций нужны отдельные присваивания. Списки подробно разбираются в уроке 25.

## Ссылки на объекты, а не копии

`y = x` **не копирует** значение: оба имени начинают ссылаться на один и тот же объект. Убедиться в этом помогает функция `id()` — она возвращает идентификатор объекта:

```python
x = 10
y = x
print(id(x) == id(y))   # True — это один и тот же объект

x = 5                   # имя x теперь указывает на другой объект
print(y)                # 10 — y всё ещё указывает на прежний
```

Для чисел, строк и `bool` разница незаметна: они **неизменяемы**, поэтому «изменить» их нельзя — можно только создать новый объект и перепривязать к нему имя.

С изменяемыми объектами (например, списками) разница принципиальна:

```python
a = [1, 2]
b = a            # копии нет: b и a — одно и то же
b.append(3)
print(a)         # [1, 2, 3] — изменился и a
print(a is b)    # True
```

Полноценную копию создают явно: `b = a.copy()` (подробнее — в уроке 25).

## Удаление переменной

```python
x = 10
del x
# print(x)   # NameError: name 'x' is not defined
```

После `del` имя исчезает. Сам объект удаляется сборщиком мусора, когда на него не осталось ни одной ссылки.

## Вывод нескольких значений

`print()` умеет выводить несколько значений сразу — по умолчанию они разделяются пробелом:

```python
a, b = 1, 2
print(a, b)   # 1 2
```

## Итоги

- Переменная — это имя, ссылающееся на объект; тип есть у значения, а не у имени.
- `snake_case` для переменных, `UPPER_CASE` для констант, `_` для ненужных значений.
- `y = x` не копирует объект: для изменяемых типов это важно помнить.
- `a, b = b, a` меняет значения местами без третьей переменной.
