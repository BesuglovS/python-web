## Арифметические операции

Базовые операции с числами:

```python
a = 10
b = 3

print(a + b)   # 13  — сложение
print(a - b)   # 7   — вычитание
print(a * b)   # 30  — умножение
print(a / b)   # 3.3333333333333335 — деление (всегда float)
print(a // b)  # 3   — целочисленное деление
print(a % b)   # 1   — остаток от деления
print(a ** b)  # 1000 — возведение в степень
```

Обратите внимание: `/` возвращает `float` даже при делении нацело — `10 / 2` даёт `5.0`, а не `5`.

## Целочисленное деление (//) и остаток (%)

Полезны для проверки чётности, разбиения чисел:

```python
num = 17
print(num // 10)  # 1 — количество десятков
print(num % 10)   # 7 — единицы
```

> **⚠️ Важно:** `//` — это **округление вниз** (floor), а не отбрасывание дробной части. Для отрицательных чисел результаты неинтуитивны:
>
> ```python
> print(-7 // 2)   # -4 (а не -3!)
> print(-7 % 2)    # 1  (остаток всегда имеет знак делителя)
> print(7 // -2)   # -4
> ```

Проверка на чётность:

```python
num = 17
if num % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
```

> **ℹ️ Замечание:** конструкцию `if / else` мы подробно разберём в уроке 10 — пока просто посмотрите, как читается условие.

**Деление на ноль** запрещено для всех трёх операций:

```python
# print(1 / 0)     # ZeroDivisionError: division by zero
# print(1 // 0)    # ZeroDivisionError: integer division or modulo by zero
# print(1 % 0)     # ZeroDivisionError: integer division or modulo by zero
```

## Составное присваивание

Короткая запись «возьми текущее значение переменной, примени операцию и сохрани результат в неё же»:

```python
x = 10
x += 5    # x = 15   — то же, что x = x + 5
x -= 3    # x = 12   — то же, что x = x - 3
x *= 2    # x = 24   — то же, что x = x * 2
x /= 4    # x = 6.0  — то же, что x = x / 4
```

Аналогично работают `//=`, `%=` и `**=`:

```python
n = 17
n //= 2   # n = 8    — то же, что n = n // 2
n %= 3    # n = 2    — то же, что n = n % 3
n **= 3   # n = 8    — то же, что n = n ** 3
```

Такая запись особенно удобна в циклах: `count += 1` увеличивает счётчик на 1, а `count -= 1` уменьшает:

```python
count = 5
while count > 0:
    print(count)   # 5 4 3 2 1
    count -= 1     # count = count - 1
```

> **ℹ️ Замечание:** `+=` работает и со строками: `s += "!"` допишет восклицательный знак в конец строки (подробнее о строках — в уроке 15). Циклы `while` разберём в уроке 17.

## Полезные функции

Встроенные функции для работы с числами:

```python
print(abs(-5))             # 5 — модуль числа
print(round(3.14159, 2))   # 3.14 — округление до 2 знаков
print(round(3.5))          # 4
print(round(2.5))          # 2 — банковское округление: половина идёт к чётному!
print(divmod(17, 5))       # (3, 2) — (17 // 5, 17 % 5)

# Сравнения
print(min(3, 7, 1))   # 1
print(max(3, 7, 1))   # 7

# Модульное возведение в степень: pow(a, b, mod) = (a ** b) % mod, но быстрее
print(pow(2, 10, 1000))   # 24 (1024 % 1000)
```

> **⚠️ Важно:** `round()` использует **банковское округление**: при ровно половине выбирается чётное значение. Поэтому `round(2.5) == 2`, а `round(3.5) == 4`. Для вывода нужного числа знаков лучше использовать f-строки из урока 7.

## Целые числа не переполняются

В отличие от C, Java или Go, `int` в Python имеет **произвольную точность** — он растёт вместе с числом, пока хватает памяти:

```python
print(2 ** 100)            # 1267650600228229401496703205376
print(10 ** 20 + 1)        # 100000000000000000001
```

Это удобно для задач, где ответ не помещается в 64 бита.

## Математический модуль (import math)

Для более сложных математических операций в Python есть модуль **math**. Чтобы использовать его функции, нужно в начале программы написать `import math` — это подключает модуль, открывая доступ к sqrt, pi, ceil и другим возможностям. Подробнее о работе с модулями и командой `import` — в уроке 35.

Пока просто запомните: строка `import math` пишется в самом верху файла, после неё все функции модуля вызываются через точку — `math.имя_функции()`.

```python
import math

print(math.sqrt(25))    # 5.0 — квадратный корень
print(math.sqrt(2))     # 1.4142135623730951

print(math.pow(2, 10))  # 1024.0 — возведение в степень (всегда float)
print(math.pow(9, 0.5)) # 3.0 — корень через степень 0.5

print(math.pi)          # 3.141592653589793 — число π
print(math.e)           # 2.718281828459045 — число e

print(math.ceil(3.1))   # 4 — округление вверх
print(math.floor(3.9))  # 3 — округление вниз

print(math.fabs(-10.5)) # 10.5 — модуль для float

# Практический пример: расстояние между двумя точками (x1, y1) и (x2, y2)
x1, y1 = 0, 0
x2, y2 = 3, 4
distance = math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2)
print(f"Расстояние: {distance:.3f}")   # Расстояние: 5.000

# Практический пример: дискриминант квадратного уравнения
a, b, c = 1, -5, 6   # уравнение x² - 5x + 6 = 0
D = b ** 2 - 4 * a * c     # дискриминант
sqrt_D = math.sqrt(D)       # квадратный корень из дискриминанта
print(f"Дискриминант: {D}")               # Дискриминант: 1
print(f"Корень из D: {sqrt_D:.3f}")       # Корень из D: 1.000
```

**Совет.** Для возведения в дробную степень не обязательно использовать `math.pow()` — можно применить оператор `**`, например `16 ** 0.5` даст `4.0`. Но `math.sqrt()` лучше читается и наглядно показывает намерение извлечь корень.

## Точность float и сравнение

Дробные числа хранятся приближённо, поэтому сравнивать их через `==` опасно:

```python
import math

print(0.1 + 0.2)                      # 0.30000000000000004
print(0.1 + 0.2 == 0.3)               # False
print(math.isclose(0.1 + 0.2, 0.3))   # True — правильный способ
```

**Для контестов.** В задачах, где ответ — вещественное число, почти всегда требуется выводить результат с **фиксированным количеством знаков** после запятой (например, 3 знака). Используйте f-строку с форматом `:.3f`: `print(f"{result:.3f}")`. Подробнее о форматировании чисел — в [уроке 7 (f-строки)](07-f-strings.html).

## Таблица приоритетов (от высшего к низшему)

Операции с более высоким приоритетом выполняются раньше:

```python
# 1.  () — скобки
# 2.  ** — возведение в степень
# 3.  +x, -x, ~x — унарные операторы
# 4.  *, /, //, % — умножение и деление
# 5.  +, - — сложение и вычитание
# 6.  <<, >> — сдвиги (побитовые операции, в курсе не рассматриваем)
# 7.  & — побитовое И
# 8.  ^ — побитовое исключающее ИЛИ
# 9.  | — побитовое ИЛИ
# 10. <, <=, >, >=, ==, !=, in, not in, is, is not — сравнения (один уровень!)
# 11. not — логическое НЕ
# 12. and — логическое И
# 13. or — логическое ИЛИ
# 14. x if условие else y — условное выражение
# 15. = — присваивание (это инструкция, а не выражение)
```

> **⚠️ Важно:** все операции сравнения имеют **одинаковый** приоритет и выполняются цепочкой слева направо. Поэтому `1 < 2 < 3` означает `1 < 2 and 2 < 3`, а `x == 5 < 10` — это `x == 5 and 5 < 10`.

Унарный минус слабее степени: `-2 ** 2` равно `-4`, потому что сначала вычисляется `2 ** 2`, а затем применяется минус.

## Примеры

Как Python вычисляет выражения:

```python
# Умножение выполняется раньше сложения
result = 2 + 3 * 4      # 2 + 12 = 14

# Скобки меняют порядок
result = (2 + 3) * 4    # 5 * 4 = 20

# Степень — самый высокий приоритет
result = 2 * 3 ** 2     # 2 * 9 = 18

# Унарный минус слабее степени
result = -2 ** 2        # -4, а не 4

# Цепочка сравнений
result = 1 < 2 < 3      # True (1 < 2 and 2 < 3)

# Логические операции
result = not True and False  # False (not True = False, False and False = False)
```

## Совет: используйте скобки

Даже если знаете приоритет, скобки делают код понятнее:

```python
a, b, c, d, e = 1, 2, 2, 3, 3

# Плохо (нужно помнить приоритет)
x = a + b * c ** d // e

# Хорошо (понятно без таблицы)
x = a + ((b * (c ** d)) // e)

print(x)   # 6 — оба варианта дают одинаковый результат
```

## Итоги

- `/` всегда возвращает `float`, `//` — округление вниз, `%` — остаток со знаком делителя.
- Для отрицательных чисел `//` и `%` работают «математически», а не как отбрасывание дробной части.
- `int` в Python не переполняется.
- `round()` и `//` округляют по-разному; `round()` использует банковское округление.
- Сравнения образуют один уровень приоритета и поддерживают цепочки.
- Дробные числа сравнивайте через `math.isclose()`, а выводите через `:.3f`.
