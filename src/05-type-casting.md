## Зачем нужно приведение типов?

Когда вы получаете данные от пользователя через `input()`, они всегда приходят в виде строки (`str`). Чтобы выполнять математические операции, строку нужно преобразовать в число:

```python
age_str = input("Сколько вам лет? ")   # пользователь ввёл "25"
age = int(age_str)                      # теперь age = 25 (int)
print("Через год будет:", age + 1)      # 26
```

> **💡 Совет:** `input()` всегда возвращает строку. Если нужны вычисления — приводите к числу!

## int() — преобразование в целое число

```python
print(int("100"))      # 100
print(int("-42"))      # -42
print(int(3.99))       # 3  — дробная часть отбрасывается, НЕ округляется
print(int(-3.99))      # -3 — у отрицательных тоже отбрасывается, а не «вниз»
print(int(" 42 "))     # 42 — пробелы по краям игнорируются
print(int("1_000"))    # 1000 — подчёркивания внутри числа допустимы
```

Для отрицательных чисел `int()` ведёт себя как **усечение к нулю**, а не как `math.floor()`: `int(-3.9) == -3`, хотя `math.floor(-3.9) == -4`.

Строка с точкой не преобразуется напрямую — сначала нужен `float()`:

```python
# int("3.14")        # ValueError
print(int(float("3.14")))   # 3
```

Работа с другими системами счисления — второй аргумент `base`:

```python
print(int("101", 2))    # 5   — двоичное число
print(int("0x1f", 16))  # 31  — шестнадцатеричное
```

## float() — преобразование в дробное число

```python
print(float("3.14"))   # 3.14
print(float(10))       # 10.0
print(float("5"))      # 5.0 — целое число в строке тоже допустимо
print(float("1e3"))    # 1000.0 — экспоненциальная запись
print(float("-2.5"))   # -2.5
```

**Запятая вместо точки.** В Python десятичный разделитель — всегда точка. `float("12,5")` выбрасывает `ValueError`, поэтому в подсказке `input()` стоит явно просить формат: `"Введите рост (м, через точку): "`.

## str() — преобразование в строку

```python
print(str(42))         # 42
print(str(3.14))       # 3.14
print(str(True))       # True
print(str(None))       # None — строка из четырёх символов
```

`print()` выводит строки **без кавычек**, поэтому `print(str(42))` и `print(42)` выглядят одинаково. Разницу показывает `repr()`:

```python
print(repr(str(42)))   # '42' — видно, что это строка
```

Полезно для склеивания чисел со строками:

```python
age = 25
print("Мне " + str(age) + " лет.")   # Мне 25 лет.
# Без str() будет TypeError!
```

> **💡 Совет:** вместо конкатенации с `str()` почти всегда удобнее f-строка: `print(f"Мне {age} лет.")` — подробности в уроке 7.

## bool() — преобразование в логическое значение

```python
print(bool(1))         # True
print(bool(0))         # False
print(bool(""))        # False (пустая строка)
print(bool("hello"))   # True  (непустая строка)
print(bool([]))        # False (пустой список)
print(bool([1, 2]))    # True  (непустой список)
```

> **⚠️ Важно:** `bool()` не разбирает текст — он проверяет только «пустоту». Поэтому `bool("False")` равно **`True`** (строка непустая), а `bool("0")` — тоже `True`.

**Запомните:** к `False` приводятся `0`, `0.0`, `""`, `[]`, `()`, `{}`, `set()`, `None` и `False`. Всё остальное — к `True`.

## Практический пример: калькулятор

```python
a = float(input("Введите первое число: "))
b = float(input("Введите второе число: "))

print("Сумма:", a + b)
print("Разность:", a - b)
print("Произведение:", a * b)
print("Частное:", a / b if b != 0 else "на ноль делить нельзя")
```

## Частые ошибки

- `int("3.14")` — **ValueError**: строка с точкой не может быть `int`. Сначала `float()`, потом `int()`.
- `int("12,5")` и `float("12,5")` — **ValueError**: нужна точка, а не запятая.
- `"Мне " + 25 + " лет"` — **TypeError**: нельзя складывать строку и число. Используйте `str(25)` или f-строку.
- `bool("False")` — это `True`, а не `False`.
- `int(input())` без проверки — если пользователь введёт буквы, программа упадёт с `ValueError`. Обработку таких ситуаций через `try/except` разберём в уроке 11.

## Итоги

- `input()` возвращает `str` — для чисел нужно явное преобразование.
- `int()` отбрасывает дробную часть (к нулю) и понимает `base` для других систем счисления.
- `float()` требует точку в качестве разделителя.
- `str(x)` даёт «человеческое» представление; `repr(x)` показывает, что это строка.
- `bool()` проверяет «пустоту», а не смысл текста.
