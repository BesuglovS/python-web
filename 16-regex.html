Урок 16 Регулярные выражения

Введение

Регулярные выражения (regex) — мощный инструмент для поиска и обработки текста по шаблону. Модуль re в Python предоставляет полный набор функций для работы с регулярными выражениями.

📌 На этом уроке вы узнаете:
  • Что такое регулярные выражения и зачем они нужны
  • Основные метасимволы: ., ^, $, *, +, ?, []
  • Функции re.search(), re.match(), re.findall()
  • Замена через re.sub() и группы захвата ()
  • Компиляция шаблонов re.compile() и флаги re.IGNORECASE

Основной материал

Регулярные выражения позволяют описывать шаблоны текста с помощью специального синтаксиса. Метасимвол . соответствует любому символу, \d — цифре, \w — букве или цифре, \s — пробельному символу. Квантификаторы * (0+), + (1+), ? (0 или 1) и {n,m} (от n до m) управляют повторениями. Группы () захватывают части совпадения. Флаги как re.IGNORECASE и re.MULTILINE меняют поведение поиска. re.compile() ускоряет многократное использование одного шаблона.

import re

text = "Email: user@example.com, Phone: +7(999)123-45-67"

# Поиск email
email = re.search(r'[\w.-]+@[\w.-]+\.\w+', text)
print(email.group())  # user@example.com

# Поиск всех цифр
digits = re.findall(r'\d+', text)
print(digits)  # ['7', '999', '123', '45', '67']

# Замена с группами
phone_pattern = r'\+(\d)\((\d{3})\)(\d{3})-(\d{2})-(\d{2})'
formatted = re.sub(phone_pattern, r'+\1 (\2) \3-\4-\5', text)
print(formatted)  # +7 (999) 123-45-67

# Компиляция шаблона
pattern = re.compile(r'\b[A-Z][a-z]+\b')  # слова с большой буквы
print(pattern.findall("Hello World from Python"))  # ['Hello', 'World', 'Python']

Ключевые выводы

  • re.search() — первое совпадение, re.findall() — все совпадения
  • re.sub() — замена по шаблону с группами захвата ()
  • Метасимволы \d \w \s . ^ $ * + ? [] {} — основа regex
  • re.compile() ускоряет многократный поиск
  • Флаги re.I, re.M, re.S изменяют поведение
